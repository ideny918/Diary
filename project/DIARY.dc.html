1DIARY — personal journal, v1
1aInteractive prototype · switch iOS / Android above the phone
A quiet place to write.

The attached design system was empty, so I set a direction: warm paper tones, Instrument Serif for the words you write and read back, Hanken Grotesk for interface text, and a single terracotta accent for actions.

Mood is a 5-point scale shown as colour, with optional emotion words once a mood is picked. Those colours carry through the week strip, calendar and insights.

Assumptions
  • Added a Write screen, since free writing is the core of the app.
  • Passcode: any 4 digits unlock. Face ID / fingerprint key unlocks instantly.
  • Photos are placeholders. Weather and location stamps are sample data.
  • Settings opens from the gear on Today; “Lock DIARY now” returns to the lock screen.
  • Android swaps the centre Write tab for a FAB and uses Material-style nav pills.
